# Rental Share Streamlit App

A Streamlit app for listing and finding rental properties in Bengaluru, designed for students and office workers.

## Features

- **List Property page**
  - Add new rental listings with property details.
  - Pick address coordinates from an interactive map click.
  - Configure property type, rent basis (daily/weekly/monthly), and pricing.

- **Find Property page**
  - Filter properties by pincode, address/title search, property type, lister type, and monthly budget.
  - Optional map-radius filtering by clicking a location on the map.

- **Bangalore Rent Map page**
  - Map-first browsing experience inspired by Bengaluru rental map sites.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
